## `01 // MISSION`

SputikOS is an open-source learning initiative focused on helping
people understand cybersecurity, operating systems, networking,
and the technologies shaping the modern information environment.

The objective is to make technical knowledge more accessible through
hands-on experimentation, reproducible labs, and community-driven
documentation.

| Principle | Objective |
|:---|:---|
| **Open Knowledge** | Learn from public resources and open-source projects |
| **Zero Trust** | Verify identities, devices, and access |
| **Practical Learning** | Build labs, test assumptions, document results |
| **Cyber Citizenship** | Promote responsible, informed participation in digital life |
